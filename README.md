## Installation
Mamba:
```
mamba env create -f env.yml
mamba activate MAIR1a-F3
```
Conda:
```
conda env create -f env.yml
conda activate MAIR1a-F3
```
Vanilla:
```
python -m pip install -r requirements.txt
```

## Running
```
python ./main.py [--verbose]
```
